# San Giovanni — Banner v12: immagine come sfondo

Aggiornamento puramente grafico basato sulla versione 11 + banner.

- La Home mantiene titolo, sottotitolo e pulsante; **il pulsante apre Calendario**.
- L’immagine «A BRACCIA APERTE» costituisce lo sfondo dell’intero banner, senza box fotografico separato.
- Asset adattati per desktop e telefono con sfumatura per conservare leggibili i testi.
- Il banner non è cliccabile nel suo complesso; si clicca soltanto il pulsante.
- Non sono necessarie migrazioni SQL né modifiche alle variabili Netlify.

## Pubblicazione

Sostituire nel repository esistente tutti i file di questa versione (stessa struttura della versione 11), preservando il collegamento a Netlify. Aggiornamento immagini incluse nel service worker.
